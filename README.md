# Eddice-Music

Este é um bot feito com o intuito de auxiliar em sessões de RPG, além de tocar músicas que são baixadas e colocadas no bot.

## Funcionalidades

**Tocar Músicas** - Nesse bot para o discord, a sua função principal vem no modo de tocar músicas, utilizando ed!help você pode ver todas as funcionalidades e como elas funcionam, necessitando baixar a música e colocá-la no bot.

**Dados** - Este bot também tem a funcionalidade de rolar dados, podendo ser de qualquer tipo que o usuário requisitar/precisar.

## Tecnologias

**Nodes.js** - Além das bibliotecas já conhecidas para esse tipo de bot, foi implementado a partir de Node, fazendo tudo por uma única linguagem, pois adiciona a ela uma parte servidor vasta.
